개인정보처리방침

메소노믹스(이하 "서비스")는 개인이 운영하는 무료 도구입니다. 서비스는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 문의를 처리하기 위해 이 방침을 둡니다.

1. 기본 원칙 — 로그인하지 않으면 서버에 아무것도 보내지 않습니다

장부 · 캐릭터 · 계산기 입력은 이용자 기기의 브라우저 저장소(localStorage)에만 저장됩니다. 운영자는 이 데이터를 볼 수 없습니다. 아래 2항의 정보는 이용자가 Google로 로그인(기기 간 동기화)을 직접 켠 경우에만 처리됩니다.

2. 처리하는 개인정보 항목과 목적

구분항목목적
로그인Google 계정 식별자(UID), 이메일 주소, 표시 이름본인 확인, 동기화 데이터를 계정별로 구분
동기화 데이터장부 기록(날짜 · 금액 · 분류 · 메모), 캐릭터 정보(이름 · 월드 · 직업 · 레벨 · 보스 설정), 계산기 입력값, 결정석 가격 수정값, 기기 구분용 무작위 값, 저장 시각여러 기기에서 같은 데이터를 쓰게 함

넥슨 Open API 키, 테마 설정은 기기에만 저장되며 서버로 보내지 않습니다. 메모란에는 다른 사람의 개인정보를 적지 마십시오.

3. 보유 기간과 파기

  • 로그인 정보와 동기화 데이터는 이용자가 ⚙ 설정 → 계정·동기화 → 탈퇴(클라우드 데이터 삭제)를 누를 때까지 보관하고, 누르면 지체 없이 삭제합니다. 별도 백업본은 두지 않습니다.
  • 서비스를 종료하는 경우 미리 공지하고 저장된 정보를 모두 삭제합니다.
  • 기기에 저장된 데이터는 이용자가 브라우저 데이터를 지우거나 앱을 삭제하면 사라집니다.

4. 처리 위탁과 국외 이전

서비스는 로그인과 데이터 저장을 위해 Google의 Firebase를 이용합니다. 개인정보를 제3자에게 제공하거나 판매하지 않습니다.

받는 자위탁 업무저장 위치항목
Google LLC
(Firebase Authentication)		Google 로그인 · 계정 관리미국 등 Google 데이터센터 (국외 이전)UID, 이메일 주소, 표시 이름
Google LLC
(Cloud Firestore)		동기화 데이터 저장대한민국 서울 리전(asia-northeast3)2항의 동기화 데이터

국외 이전은 이용자가 로그인 버튼을 누를 때 네트워크로 전송되는 방식으로 이루어지며, 보유 기간은 3항과 같습니다. 이전을 원하지 않으면 로그인하지 않고 쓰면 되며, 이 경우에도 동기화를 뺀 모든 기능을 쓸 수 있습니다. 문의: Firebase 개인정보 보호.

5. 자동으로 수집될 수 있는 정보

  • 서비스는 광고 · 방문 통계 · 추적 도구를 쓰지 않습니다.
  • 웹사이트를 호스팅하는 GitHub Pages(GitHub, Inc.)가 접속 기록(IP 주소 등)을 보안 목적으로 남길 수 있습니다. 이는 GitHub의 개인정보 처리방침을 따릅니다.
  • 넥슨 Open API 기능을 쓰면 이용자의 기기가 넥슨 서버(open.api.nexon.com)에 직접 요청합니다. 설치판은 업데이트 확인을 위해 GitHub에 버전 정보를 요청합니다.
  • 오프라인 사용을 위해 서비스 파일을 기기에 캐시(Service Worker)합니다. 쿠키는 쓰지 않으며, Google 로그인 과정에서 Google이 자체 쿠키를 쓸 수 있습니다.

6. 이용자의 권리

  • 열람 · 내려받기: ⚙ 설정 → 데이터 → 백업(JSON)으로 저장된 데이터를 모두 내려받을 수 있습니다.
  • 정정: 서비스 화면에서 직접 고치면 동기화로 반영됩니다.
  • 삭제: ⚙ 설정 → 계정·동기화 → 탈퇴로 클라우드의 데이터와 로그인 정보를 지웁니다.
  • 처리 정지: 로그아웃하면 동기화가 멈춥니다.
  • 위 방법으로 처리가 안 되면 아래 문의처로 요청할 수 있으며, 지체 없이 처리합니다.

7. 만 14세 미만 이용자

만 14세 미만은 법정대리인의 동의 없이 로그인(동기화) 기능을 쓸 수 없습니다. 로그인하지 않으면 개인정보를 처리하지 않으므로 나머지 기능은 그대로 쓸 수 있습니다.

8. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • 데이터베이스 보안 규칙으로 로그인한 본인만 자기 데이터를 읽고 쓸 수 있게 막습니다. 운영자 외에 관리 권한을 가진 사람은 없습니다.

10. 방침의 변경

이 방침을 바꾸면 시행 7일 전부터 이 페이지에 공지합니다. 이용자에게 불리한 변경은 30일 전에 공지합니다.

이용약관

1. 서비스

메소노믹스는 메이플스토리 메소 장부, 목표 도달일 계산기, 보스 수익 계산을 제공하는 무료 도구입니다. 서비스를 이용하면 이 약관에 동의한 것으로 봅니다.

2. 비공식 서비스

이 서비스는 개인이 만든 비공식 팬 도구로, 넥슨코리아와 관련이 없으며 넥슨코리아가 보증하거나 후원하지 않습니다. 메이플스토리(MapleStory)와 관련 명칭 · 상표는 넥슨코리아의 자산입니다. 일부 데이터는 넥슨 Open API를 이용합니다(Data based on NEXON Open API).

3. 계산 결과

도달일 · 보스 수익 · 결정석 가격 · Open API로 추정한 지출 금액은 참고용이며, 게임 패치나 입력값에 따라 실제와 다를 수 있습니다. 운영자는 결과의 정확성을 보장하지 않으며, 이를 근거로 한 게임 안의 결정과 그 결과는 이용자가 책임집니다.

4. 데이터 보관

데이터는 기본적으로 이용자 기기에 저장됩니다. 브라우저 데이터 삭제 · 기기 분실 등으로 데이터가 사라질 수 있으니 ⚙ 설정의 백업을 이용하십시오. 운영자는 고의 또는 중대한 과실이 없는 한 데이터 손실에 책임을 지지 않습니다.

5. 금지 행위

  • 서비스나 서버의 정상적인 운영을 방해하는 행위 (과도한 자동 요청 등)
  • 다른 사람의 계정이나 데이터에 접근하려는 행위
  • 서비스를 법령에 어긋나는 목적으로 쓰는 행위

6. 서비스 변경 · 중단

운영자는 서비스의 기능을 바꾸거나 중단할 수 있습니다. 동기화처럼 저장된 데이터에 영향을 주는 중단은 미리 공지하고, 데이터를 내려받을 기간을 둡니다.

7. 약관의 변경

약관을 바꾸면 시행 7일 전부터(이용자에게 불리하면 30일 전부터) 이 페이지에 공지합니다.
