# UI 흐름 참고 — 메이플스카우터 · 메이플로드 · 메애기 (조사 2026-11-15)

비슷한 이용자층이 함께 쓰는 세 사이트의 흐름을 보고, 메소노믹스에 가져올 만한 것만 추렸다.

## 사이트별로 본 것

### 메이플스카우터 (maplescouter.com) — "주간 보스 정산"
- 첫 화면에 **3단계 안내**: ① 본캐 닉네임 검색 → 같은 월드 캐릭터를 불러옴 ② 캐릭터별로 보스를 고르거나 **추천 구성** ③ 주간 총수익 · 캐릭터별 수익 확인, **프리셋으로 저장**.
- 머리글에 **닉네임 검색창**이 늘 있고, 자주 쓰는 도구를 **즐겨찾기**로 고정.
- 홈에 **최신 업데이트 표**(날짜 · 내용).
- 운영사 서버의 API 키로 조회한다(그래서 이용자는 키가 없어도 됨). 우리는 서버가 없어 그대로는 못 따라 함.

### 메이플로드 (mapleroad.kr) — 링크 길잡이 + 계산기
- 계산기 한 장의 구성이 일정함: **제목 + 해시태그** → 입력 표(보스 · 난이도 · 파티원 · 이번 주) → **계산하기** → 결과 표 → **업데이트 내역**(날짜 · 패치 버전 KMS v.x) → **계산기 소개**(입력 방법과 가정: "파티원 2인 이상이면 내림", "목요일 기준", "1주 내외 오차").
- 파티원 수는 숫자 입력 대신 **드롭다운(X · 1~6)**.
- 꼬리말: 연락 이메일 + 카카오톡 오픈채팅, "not associated with NEXON Korea", 개인정보처리방침.
- 다른 도구들을 **파트너 링크**로 모아 보여 줌 — 새 도구를 알리는 통로("링크 추가 환영", 문의/제보는 카카오톡).

### 메애기 (meaegi.com) — 캐릭터 검색
- 첫 화면 한가운데 큰 검색창, 옆에 인기 캐릭터 · 랭킹 요약.
- **진행 중 이벤트 · 캐시샵 D-day 카드**(넥슨 공지 기반), 공지사항 · 업데이트 목록.

## 제안

**A. 바로 할 수 있는 것 (서버 필요 없음)**
1. **추천 구성**: 캐릭터마다 "잡을 수 있는 마지막 보스 · 난이도"만 고르면, 그 앞의 보스를 비싼 순으로 주 12회까지 자동으로 채움. 이후에 하나씩 고칠 수 있음. → **완료(2026-11-15)**: 보스 시트 맨 위 "추천 구성" 선택 + 채우기(`store.js` recommend). 가격을 난이도 대용으로 써서, 고른 보스까지의 보스마다 그 가격 이하 가장 비싼 난이도를 고르고 익스트림은 고른 보스만. 원래 파티 인원 유지, 되돌리기 토스트.
2. 보스 수익 · 계산기 화면 아래에 **"계산 기준"** 접는 칸: 결정석 가격 기준일 · 출처, 파티 분배 내림, 캐릭터당 주 12회 · 월드당 주 90개, 목요일 0시 리셋. → **완료(2026-11-15)**: 캐릭터 · 계산기 맨 아래 `<details>`(`basis.js`). 숫자는 `bosses.js` · `core.js`에서 읽고, ⚙에서 고친 가격이 있으면 개수와 설정 링크. 계산기 쪽엔 도달일 계산 가정(목요일 주보 · 1일 월보 · 사냥 · 일회성 · 정기 지출 · 월 평균 환산)을 앞에 붙임.
3. ⚙ 설정에 **"새 소식"**(날짜 · 한 줄) — 정식 서비스로 보이는 신뢰 요소, 가격 갱신을 알리는 통로.
4. 캐릭터 탭 빈 화면의 중복 버튼 정리.

**B. 서버가 필요한 것** — 닉네임만으로 캐릭터 불러오기
- 서비스 단계 키를 서버(예: Cloudflare Workers)에 두고 대신 조회. 키를 서버 안에 두는 것은 "노출"이 아님.
- 하지만 본인 계정 캐릭터 목록 · 지출 기록 API는 여전히 이용자 키가 필요. 닉네임 → 레벨 · 직업 · 월드 정도만 해결됨.
- 서버 운영 · 비용 · 서비스 단계 등록이 먼저라 지금은 보류.

**C. 사용자 결정 · 사용자 일**
- 공개 문의 이메일 또는 카카오톡 오픈채팅을 둘지.
- 메이플로드 같은 링크 모음 사이트에 등록 요청.
