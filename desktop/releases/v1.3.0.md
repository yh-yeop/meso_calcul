- 앱 이름 · 시작 메뉴 · 바탕 화면 바로가기 · 설치된 앱 목록 이름이 "메소 계산기" → "메소노믹스" (Android 앱 이름도)
- Windows: 1.2.0 이하에서 업데이트하면 옛 "메소 계산기"를 알아서 지우고 새 이름으로 설치합니다. 시작 메뉴 바로가기는 새 이름으로 다시 만들고, 바탕 화면 바로가기가 있었으면 그것도 새로 만듭니다
