메소 계산기의 첫 Windows 설치판입니다.

- 브라우저 없이 창 하나로 메소 장부 · 목표 도달일 계산기 · 캐릭터별 보스 수익을 씁니다. 화면은 웹(https://yh-yeop.github.io/meso_calcul/)과 같고, 웹이 바뀌면 앱도 다음 실행부터 따라 바뀝니다
- Google 로그인 동기화가 웹과 똑같이 동작합니다
- 열 때마다 새 버전을 확인하고, 새 버전이 있으면 받아서 설치합니다 (⚙ 설정 → 앱 → 업데이트 확인으로 언제든 다시 확인)
- 사용자 폴더에 설치되어 관리자 권한이 필요 없습니다. 지우려면 Windows 설정 → 앱
- 앱의 데이터는 브라우저와 따로 저장됩니다. 브라우저에서 쓰던 장부는 ⚙ 데이터의 백업 · 불러오기나 Google 동기화로 옮기세요
